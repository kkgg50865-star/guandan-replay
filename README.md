# 掼蛋复盘

Windows 牌局复盘工具，支持读取“来几局”的录像号，以及在桌面微信中选择“天天爱掼蛋”的已收藏牌局。软件安装在 Windows 电脑上；试用、登录和会员状态由软件原有服务处理。

## 下载与安装

**[下载 Windows 安装包 v1.4.8](https://github.com/kkgg50865-star/guandan-replay/releases/latest)**。在发布页面找到 `GuandanReplay-Setup-v1.4.8.exe`，点击下载后运行安装。

GitHub 自动提供的 `Source code (zip)` 只包含本仓库公开资料，不是软件安装包。请下载名称含 `Setup` 的 EXE 文件。

安装包面向 64 位 Windows。安装后打开“掼蛋复盘”，首次使用按软件提示注册并登录。各版本的适用范围和注意事项以对应的发布说明为准。

## 两种牌局来源

- **来几局**：先在 MuMu 模拟器中登录“来几局”，打开并播放一局录像，记下 5 位录像号。随后在电脑端“掼蛋复盘”中输入录像号，点击“读取本局”。
- **天天爱掼蛋**：先打开电脑端“掼蛋复盘”，再从桌面微信进入“天天爱掼蛋”并收藏目标牌局。返回本软件，选择收藏牌局并进入复盘。

详细步骤见 [使用说明](使用说明.md)。MuMu 仅用于“来几局”牌局来源；微信小程序牌局使用桌面微信。
